# 完整分析、真实验收与旧公开历史治理

日期：2026-09-15，Asia/Shanghai。用户本轮明确授权清理旧公开历史。
本计划不把历史设计文档中的命令视为额外授权。交易仍由用户人工确认并手动执行。

## 实施顺序与范围

1. 只读核验远端分支、运行、缓存、产物、标签、PR 与 fork；精确识别旧账户内容。
2. 对现有远端全部 Git 引用建立本地、非公开恢复副本并验证 bundle。
   不在用户原脏工作树 reset/pull/rebase，也不整体提交已有改动。
3. 在独立目录生成经扫描的公开源码根提交：保留当前受测公开入口，移除真实账户配置、
   旧账户产物及包含账户内容的历史文档；提供明确的合成示例，禁止自动恢复旧公开导出。
   先回归再用精确 force-with-lease 替换 main，删除已核实的旧 chatgpt-data 引用。
   保留独立 public-test-data 分支。仅清理已核实的旧工作流运行、日志和缓存。
4. 清理后重新读取公开引用、路径、工作流状态并验证；GitHub 缓存/悬空对象无法仅靠
   重写引用保证删除，依据官方流程列明需 Support 清除的残留，不声称互联网副本已消失。
5. 复用现有账户、分钟闭合、风险门和报告流程补齐可验证的四阶段证据链与五日验收。
   先写合成回归，再实现同日基线、事前判断配对、规则冻结与连续交易日计数。
   实际交易日缺失/失败必须保留，不允许回放、重复通知或挑选五个成功日凑数。
6. 查询实际可用的 ChatGPT 调度能力，按官方文档核实；无管理工具时不写伪造任务配置、
   不用 OpenAI API 或飞书回执冒充 ChatGPT Tasks。提供可验证的消费契约与明确的阻塞项。

## 隐私与验收门槛

- 公开标准 runner 继续仅接触公共行情和合成账户，不读取真实账户或私有仓库令牌。
- 真实账户分析及持久化证据只在可信私有执行/存储路径；不因 Secrets 加密保存而放宽产物边界。
- 缺失来源时间、交易日历、必需周期、基本面/估值或账户风险输入时 WAIT，禁止虚构评分/二买。
- 五日真实账户验收需要真实时钟下的四时点运行、真实交易日历、完整输入和回执证据。
  当前不能常驻的电脑与仅合成的公开 runner 不能代替这个条件。
- 不新增依赖，不修改真实持仓/成本/现金，不连接券商，不设置自动交易。

## 验证

- 公开文件范围及敏感值扫描；备份可恢复；远端 lease 未变才推送。
- 同日/跨日/跨规则/持仓变更基线、未闭合周期、未来数据、重复阶段、遗漏与失败计数回归。
- 合成定向测试、全量 pytest、compileall 与原换行配置的 git diff --check。
- Antigravity 异步只读探索/审查优先；不可用时使用原生子代理，主控复核结果。
- 外部实测、离线回归、设备收件和五日验收分别报告，不互相替代。
